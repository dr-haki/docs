One of the tips that I liked the most is the using the Interfaces to actually document really well what the method is doing.

This makes the implementation layer readable only for the logic.

The Interface is the actual documentation. Where the book needs to be read. The Implementation layer is where the action lies. It is like the Manga (Interface) -> Anime (Implementation).
